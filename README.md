# oioic
OIOIC，中文名“道智编程”，高智慧编程语言（OIOIC语言，简称 O语言），完全兼容C语言，高维度扩展了C语言，全新全优全功能OOP范式！OIOIC道智编程，大道至简，遵行天道的高智慧编程语言。   

【 OIOIC版权声明 】  
1. OIOIC属于所有人，所有人都应该关心爱护发展OIOIC道智编程。
2. 所有人都可以使用OIOIC开发软件。
3. 所有人都可以使用OIOIC创新发明发表论文，在代码和论文中需说明是以OIOIC原创为基础的创新发明。

【 OIOIC项目发展历史 】
2007年‌：开发者赵平智推出OIOIC对象模型v1.0版，这是该项目的首个正式公开版本。
2008年‌：项目正式在Google Code开源托管，同步发布《OIOIC Primer（入门教程）第一版》中文教程包。
2009年‌：项目在Google Code平台迭代更新至1.0.6版本，同步发布《OIOIC Primer（入门教程）第二版》中英文教程包。
2011年‌：项目在Google Code平台迭代更新至1.0.18版本。
后来托管地址code.google.com/p/oioic已随Google Code平台关停。
【注】该项目全程为OIOIC作者赵平智主导，并非Google官方推出的产品。，
2026年：作者赵平智在Gitee和GitHub重新发布OIOIC项目，并为OIOIC起了中文名“道智编程”，定义OIOIC是高智慧编程语言（OIOIC语言，简称 O语言），完全兼容C语言，高维度扩展了C语言，全新全优全功能OOP范式。


【 概念定义 】

1. OIOIC语言，简称 O语言。“O”也象征圆满完美，C语言的“C”是缺口圆不完美，O语言高智慧高维度补全C语言使之圆满完美。
2. OIOIC范（範），简称 O范。比如说：开发一个O范，设计一个O范，做一个O范。范：模子，模板。O范不用O类，因为类与累谐音，不好听。
3. OIOIC对象，简称 O象，O范的运行实例。象：形状，样子，事物的外表形态。
4. OIOIC库，简称 O库，存放O范的仓库。
5. OIOIC软件世界，简称O世界。
