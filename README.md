# oioic
OIOIC，中文名“道智编程”，全新全功能C语言OOP技术，大道至简，遵行天道的高智慧编程技术！   

【 OIOIC版权声明 】  
1. OIOIC属于所有人，所有人都应该关心爱护发展OIOIC道智编程。
2. 所有人都可以使用OIOIC开发软件。
3. 所有人都可以使用OIOIC创新发明发表论文，在代码和论文中需说明是以OIOIC原创为基础的创新发明。

【 OIOIC项目发展历史 】
2007年‌：开发者赵平智推出OIOIC对象模型v1.0版，这是该项目的首个正式公开版本。
2008年‌：项目正式在Google Code开源托管，同步发布《OIOIC Primer（入门教程）第一版》中文教程包。
2009年‌：项目在Google Code平台迭代更新至1.0.6版本，同步发布《OIOIC Primer（入门教程）第二版》中英文教程包。
2011年‌：项目在Google Code平台迭代更新至1.0.18版本。
后来托管地址code.google.com/p/oioic已随Google Code平台关停。
【注】该项目全程为OIOIC作者赵平智主导，并非Google官方推出的产品。
2026年：作者赵平智在Gitee和GitHub重新发布OIOIC项目，并为OIOIC起了中文名“道智编程”。
